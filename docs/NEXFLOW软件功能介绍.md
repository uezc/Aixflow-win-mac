# NEXFLOW V2 软件功能介绍

## 一、软件定位

**NEXFLOW V2** 是一款基于 Electron 的 **AI 多模态工作流平台**，通过可视化节点编排，将文本、图片、视频、音频、大语言模型等模块连线组合，实现从创意输入到 AI 生成的完整流程。

**核心特点**：节点化编排、多模态 AI、实时保存、跨平台（Windows / macOS / Linux）

---

## 二、核心功能

### 2.1 画布与编排

- **节点化编排**：拖拽连线，自由组合文本、LLM、图片、视频、音频、角色、3D 视角等模块
- **实时保存**：画布内容（节点、连线、文字、图片、视频、模块大小位置）自动持久化，无需手动保存
- **缩放与平移**：滚轮缩放、拖拽空白处平移画布
- **连接线样式**：支持曲线 / 直角两种样式，不兼容连线时目标节点显示红色边框
- **连线删除**：点击连线高亮 → 再次点击同一条线出现剪刀图标 → 点击剪刀删除；也可选中后按 Delete / Backspace

### 2.2 文本模块

- **功能**：输入或编辑文本，作为工作流的数据源
- **可连接**：LLM、文本拆分、图片、视频、音频
- **典型用途**：视频描述、图片提示词、LLM 输入、TTS 文本等

### 2.3 大语言模型（LLM）

- **功能**：接入大模型进行对话、续写、改写
- **输入**：来自文本、文本拆分等节点
- **输出**：生成文本，可继续连到图片、视频、音频
- **操作**：连接文本节点 → 右侧面板输入提示词 → 选择模型（如 Gemini）→ 点击「运行」
- **人设**：可保存为人设，供后续对话复用

### 2.4 文本拆分

- **功能**：将长文本按规则拆分为多段
- **典型用途**：长剧本分段生成、批量 TTS 等

### 2.5 图片模块

| 模式 | 功能 |
|------|------|
| **文生图** | 输入提示词生成图片，支持多参考图、多分辨率与比例 |
| **图生图** | 以参考图为依据生成新图，支持拖拽排序、画板标记 |
| **图像放大** | 对指定图片进行高清放大 |
| **抠图** | 智能抠图，去除背景 |
| **去水印** | 去除图片水印 |
| **3D 视角控制** | 调节旋转、缩放、FOV，输出摄影语义供下游使用 |

**常用模型**：banana 2.0、Nano banana、Midjourney v7、Grok video3、Seedream 系列等

### 2.6 视频模块

| 模式 | 功能 |
|------|------|
| **文生视频** | 根据文本描述生成视频 |
| **图生视频** | 以参考图为起点生成视频 |
| **口型同步** | 图片 + 音频输入，生成与台词同步的口型视频 |

**常用模型**：Sora 2 / Sora 2 Pro、Kling、万相 Wan、Rhart 系列、Kling Video O1、LTX 2.3 口型同步、海螺、全能视频等

**辅助功能**：裁剪（双指针进度条选择区间）、下载

### 2.7 音频模块

| 功能 | 说明 |
|------|------|
| **语音合成（TTS）** | 文本转语音，支持 Index-TTS2（参考音克隆）等 |
| **全能写歌** | 输入歌词、风格、歌名，生成完整歌曲 |
| **人声分离** | 将音频分离为人声与背景音 |
| **裁剪** | 双指针选择区间，裁剪音频片段 |

### 2.8 角色模块

- **功能**：从视频生成角色形象并保存到角色库
- **输入**：仅接收来自视频节点的输入
- **算力**：支持核心算力（BLTCY Sora）与插件算力（RunningHub）
- **保存**：生成后可保存到角色库，供后续工作流使用

### 2.9 3D 视角控制器

- **功能**：对图片进行多视角渲染，输出摄影语义
- **输入**：仅接收来自图片节点的输入
- **输出**：供下游 AI 使用的摄影语义

## 三、双平台算力

| 算力类型 | 平台 | 主要用途 |
|---------|------|----------|
| **核心算力** | BLTCY | 大模型对话、Sora2 官方、图生图等 |
| **插件算力** | RunningHub | 文生图、抠图、去水印、可灵/万相/海螺/口型同步等视频、TTS、工作流应用 |

顶部状态栏实时显示双平台余额，便于监控算力消耗。

---

## 四、项目管理

- **项目列表**：新建、重命名、删除、排序项目
- **工程导出**：支持导出 `.nexflow` 工程包（ZIP 格式：JSON + 素材），便于分享与备份

---

## 五、任务列表与批量运行

- **任务列表**：左侧边栏显示进行中的图片、视频、音频任务及状态
- **批量运行**：按依赖顺序依次执行可执行节点（LLM、图片、视频、音频）

---

## 六、设置与配置

- **API Key**：配置 BLTCY、RunningHub 等平台的 API Key
- **主题**：暗黑 / 明亮
- **画布**：连接线样式（曲线/直角）、波点大小
- **阿里云 OSS**：可选，用于图片/视频上传（`.env` 中配置）
- **检查更新**：检测并安装新版本

---

## 七、典型工作流示例

### 文生视频
文本节点 → 输入描述 → 连到视频节点 → 选择模型（如 Sora 2）→ 文生视频

### 图生视频
图片节点 → 上传或生成参考图 → 连到视频节点 → 输入提示词 → 图生视频

### 口型同步
图片节点（角色）+ 音频节点（台词）→ 连到视频节点 → 选择 LTX 2.3 口型 → 生成

### 角色创建
视频节点 → 输入描述或上传参考视频 → 连到角色节点 → 生成并保存到角色库
