# NEXFLOW 简介与使用说明

## 一、软件简介

**NEXFLOW V2** 是一款基于 Electron 的 **AI 工作流平台**，采用可视化节点编排方式，将文本、图片、视频、音频、大语言模型（LLM）等模块通过连线组合，实现从创意输入到 AI 生成的完整流程。

### 核心特点

- **节点化编排**：拖拽连线，自由组合文本、LLM、图片、视频、音频、角色、3D 视角等模块
- **多模态 AI**：支持文生图、图生图、文生视频、图生视频、语音合成、智能抠图等
- **项目与数据持久化**：画布内容（节点、连线、文字、图片、视频等）自动保存到本地
- **跨平台**：支持 Windows、macOS、Linux

### 技术架构

- **前端**：React + React Flow + TypeScript + Vite + Tailwind CSS
- **桌面框架**：Electron
- **AI 对接**：主进程 IPC 直连，无跨域限制

## 二、快速开始

### 1. 首次运行

- **Windows**：运行安装包后，从桌面或开始菜单启动 NEXFLOW
- **macOS**：解压 zip 后，将 NEXFLOW.app 拖入「应用程序」
- **Linux**：解压后执行 `chmod +x nexflow && ./nexflow`，或双击桌面快捷方式

> Linux 下若以 root 运行，需加 `--no-sandbox` 参数

### 2. 必要配置

- **API Key**：在「设置」中填入 BLTCY、RunningHub 等 AI 平台的 API Key
- **阿里云 OSS**（用于图片/视频上传）：在项目根目录创建 `.env`，填入 `OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET`、`OSS_REGION`、`OSS_BUCKET`

## 三、模块与连线规则

### 模块类型

| 模块 | 说明 | 输入 | 输出 |
|------|------|------|------|
| **文本** | 输入/编辑文本 | — | 文本 |
| **大语言模型** | LLM 对话、续写 | 文本 | 文本 |
| **文本拆分** | 将长文本按规则拆分 | 文本 | 文本 |
| **图片** | 图生图、展示 | 文本/图片 | 图片 |
| **视频** | 文生视频、图生视频 | 文本/图片 | 视频 |
| **角色** | AI 生成角色形象 | 视频 | — |
| **声音** | 语音合成、参考音 | 文本/音频 | 音频 |
| **3D视角控制器** | 多视角渲染 | 图片 | 图片 |

### 连线规则（简化）

- **文本** → 可接：LLM、文本拆分、图片、视频  
- **LLM** → 可接：文本拆分、图片、视频  
- **图片** → 可接：LLM、视频、3D视角控制器  
- **视频** → 可接：图片、角色  
- **角色** → 仅接收来自视频的输入，无输出  
- **3D视角控制器** → 仅接收来自图片的输入  

拖拽连接线时，不兼容的模块会显示红色边框提示，创建菜单中不会出现不可用的模块。

## 四、基本操作

### 画布操作

- **添加节点**：从左侧或拖拽连接线松开后，在菜单中选择模块类型
- **连线**：从节点右侧绿点拖出，连接到目标节点左侧绿点
- **删除**：选中节点或连线后按 `Delete` 或 `Backspace`
- **缩放/平移**：滚轮缩放，拖拽空白处平移

### 节点操作

- **调整大小**：拖拽节点边缘或角落
- **编辑内容**：单击节点进入编辑模式，输入文本或选择文件
- **批量运行**：使用「批量运行」按钮依次执行可执行节点

### 快捷操作

- **F11**：窗口全屏切换
- **设置**：可切换暗黑/明亮主题、配置 API Key 等

## 五、典型工作流示例

### 文生视频

1. 添加「文本」节点，输入视频描述
2. 添加「视频」节点
3. 将文本连到视频
4. 在视频节点中选择模型（如 Sora2）、比例、时长
5. 点击「文生视频」生成

### 图生视频

1. 添加「图片」节点，上传或生成参考图
2. 添加「视频」节点
3. 将图片连到视频
4. 输入提示词，点击「图生视频」

### 角色创建

1. 添加「视频」节点，输入角色描述或上传参考视频
2. 添加「角色」节点
3. 将视频连到角色
4. 在角色节点中完成生成与保存

## 六、常见问题

### 图片/视频加载失败

- 检查项目文件夹中是否存在对应资源
- 若使用 OSS，确认 `.env` 中 OSS 配置正确

### 生成失败：未返回 taskId

- 多为 API 限流或配置问题，检查 API Key 与余额

### Linux 下无法启动

- 若以 root 运行，使用：`./nexflow --no-sandbox`
- 或创建普通用户运行
