# NEXFLOW V2 教学视频脚本素材 — 详细功能说明

> 本文档供 Gemini 等 AI 生成教学视频讲解大纲与脚本使用。内容按「界面结构 → 功能模块 → 操作流程」组织，便于拆分为视频章节。

---

## 第一部分：软件概述与首次启动

### 1.1 软件定位

NEXFLOW V2 是一款 **AI 多模态工作流平台**，基于 Electron 桌面应用，核心特点：

- **节点化编排**：通过拖拽节点、连线，将文本、图片、视频、音频、大语言模型等模块串联成工作流
- **多模态 AI**：文生图、图生图、文生视频、图生视频、语音合成、人声分离、抠图、去水印等
- **实时保存**：画布内容自动持久化，无需手动保存
- **跨平台**：支持 Windows、macOS、Linux

### 1.2 首次启动与授权

- **启动方式**：Windows 从桌面/开始菜单；macOS 将 NEXFLOW.app 拖入应用程序；Linux 执行 `./nexflow`
- **授权激活**：首次使用需输入激活码激活。授权到期后无法进入画布，仅可访问项目列表；重新激活后可继续使用
- **激活入口**：若未激活，进入应用后会提示输入激活码

### 1.3 主界面布局

- **顶部栏**：左侧返回按钮、项目名称、暗黑/明亮主题切换、波点大小与连接线样式设置、全屏、设置入口
- **余额显示**：顶部显示 BLTCY、RunningHub 等平台余额，用于算力消耗
- **左侧边栏**：项目列表、任务列表（生成中的图片/视频/音频任务及状态）
- **中央画布**：节点编排区域，支持缩放、平移
- **右侧面板**：选中节点后显示该节点的配置面板（提示词、模型、参数等）

## 第二部分：项目管理

### 2.1 项目列表

- **入口**：点击顶部返回按钮或从画布返回，进入项目卡片页
- **操作**：新建项目、重命名、删除、排序
- **项目卡片**：显示项目名称、最后修改时间，点击进入画布

### 2.2 项目数据

- **自动保存**：节点、连线、文字、图片、视频、模块大小与位置均自动保存
- **存储**：本地 electron-store，按项目 ID 存储
- **导出/导入**：支持导出 .nexflow 工程包，便于分享或备份

## 第三部分：画布与节点基础操作

### 3.1 画布操作

- **缩放**：鼠标滚轮
- **平移**：拖拽画布空白处
- **添加节点**：
  - 方式一：从左侧拖拽连接线到空白处松开，弹出菜单选择模块类型
  - 方式二：通过创建菜单（具体入口以实际 UI 为准）
- **连线**：从节点右侧绿色连接点拖出，连接到目标节点左侧连接点
- **删除节点/连线**：选中后按 Delete 或 Backspace
- **删除连线（专用方式）**：第一次点击连线高亮，第二次点击同一条线出现剪刀图标，点击剪刀删除

### 3.2 节点通用操作

- **选中**：单击节点，选中后显示绿色边框
- **调整大小**：拖拽节点右下角圆弧手柄
- **编辑标题**：双击节点左上角标题进入编辑
- **移动**：拖拽节点主体（非连接点、非手柄）

### 3.3 连接线样式

- **曲线 / 直角**：在顶部暗黑模式设置中可切换连接线为曲线或直角
- **不兼容提示**：将不兼容的节点连线时，目标节点会显示红色边框

## 第四部分：模块详解

### 4.1 文本模块 (Text / MinimalistText)

**功能**：输入或编辑文本，作为工作流的数据源

**操作**：
- 单击进入编辑，输入文本
- 可连接：LLM、文本拆分、图片、视频、音频
- 拖拽右下角调整模块大小

**典型用途**：视频描述、图片提示词、LLM 输入、TTS 文本等

---

### 4.2 大语言模型模块 (LLM)

**功能**：接入大语言模型进行对话、续写、改写

**输入**：来自文本、文本拆分等模块的文本
**输出**：生成后的文本，可继续连到图片、视频、音频等

**操作**：
- 连接文本节点后，在右侧面板输入或编辑提示词
- 选择模型（如 Gemini）
- 点击「运行」生成
- 可保存为人设，供后续对话复用

**典型用途**：扩写视频描述、改写提示词、生成歌词等

---

### 4.3 文本拆分模块 (TextSplit)

**功能**：将长文本按规则拆分为多段

**输入**：来自文本、LLM 的文本
**输出**：拆分后的多段文本

**典型用途**：长剧本分段生成、批量 TTS 等

---

### 4.4 图片模块 (Image)

**功能**：文生图、图生图、图像处理

#### 4.4.1 文生图模式

- **提示词**：在右侧面板的大输入框中输入描述
- **提示词标签**：点击「图像放大」「多机位九宫格」「电影级光影校正」「角色三视图」「画面推演 - 5秒前」「画面推演 - 3秒后」等，自动填入对应模板文案
- **参考图**：可选，最多 10 张（部分模型限制不同）
- **模型**：banana 2.0、Nano banana、Midjourney v7、Grok video3、Seedream 4.5、Seedream v5
- **分辨率**：1k、2k、4k（部分模型）
- **比例**：1:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9、21:9
- **Seedream 专用**：可自定义宽高

#### 4.4.2 图生图模式

- **触发**：当有参考图连接或上传时，自动切换为图生图模式
- **参考图**：从其他图片节点连线，或本地上传，支持拖拽排序
- **模型**：图生图模式下部分模型不可用（如 Midjourney v7）
- **参考图数量与模型**：≤2 张时全部可用；2–5 张时部分模型；>5 张时 banana 2.0、Seedream 系列

#### 4.4.3 辅助功能

- **图像放大**：下拉选择「放大第 X 张图」，对多张图中的指定张进行放大
- **画板工具**：选中图片节点后，点击「画板」在图片上绘图标记，便于图生图时表达意图
- **3D 视角控制**：选中后调节旋转、缩放、FOV，输出摄影语义供下游使用
- **抠图**：对生成图片进行智能抠图
- **去水印**：对生成图片进行去水印

#### 4.4.4 下载

- 左上角下载按钮，支持远程 URL 与本地资源下载到指定文件夹

---

### 4.5 视频模块 (Video)

**功能**：文生视频、图生视频、口型同步

#### 4.5.1 文生视频

- **输入**：文本节点连接的描述
- **提示词**：在右侧面板输入视频描述
- **模型**：Sora 2、Sora 2 Pro、Kling、Wan、Rhart、Kling Video O1、LTX 2.3 口型同步等
- **比例**：16:9、9:16 等
- **分辨率**：部分模型支持 720p、1080p、4k

#### 4.5.2 图生视频

- **输入**：图片节点连接的参考图
- **提示词**：描述画面变化或动作
- **部分模型**：需同时连接图片与音频（口型同步）

#### 4.5.3 口型同步 (LTX 2.3)

- **输入**：图片（角色参考图）+ 音频（台词）
- **输出**：口型与音频同步的视频

#### 4.5.4 裁剪

- **入口**：选中视频节点后，点击下方「裁剪」按钮
- **弹窗**：全屏背景虚化，中央为视频预览与双指针进度条
- **操作**：拖拽前后两个指针选择裁剪区间，可播放预览，点击「确认」执行裁剪
- **下载**：左上角下载按钮

---

### 4.6 音频模块 (Audio)

**功能**：语音合成、人声分离、全能写歌、参考音

#### 4.6.1 语音合成 (TTS)

- **输入**：文本节点连接的文本
- **模型**：Index-TTS2（需上传参考音）、全能写歌等
- **参考音**：Index-TTS2 需上传参考音以模仿音色

#### 4.6.2 全能写歌

- **输入**：歌词、风格描述、歌曲名
- **输出**：生成的歌曲音频

#### 4.6.3 人声分离

- **输入**：来自视频提取的音频或上传的音频
- **输出**：人声 / 背景音二选一

#### 4.6.4 裁剪

- **入口**：选中音频节点后，点击下方「裁剪」按钮
- **弹窗**：全屏背景虚化，中央为音频播放器与双指针进度条
- **播放**：仅播放裁剪区间内的声音
- **操作**：拖拽双指针选择区间，点击「确认」执行裁剪
- **下载**：左上角下载按钮

---

### 4.7 角色模块 (Character)

**功能**：从视频生成角色形象并保存到角色库

- **输入**：仅接收来自视频节点的输入
- **操作**：上传或连接视频，设置时间戳，生成角色形象
- **保存**：生成后可保存到角色库，供后续使用

---

### 4.8 3D 视角控制器 (CameraControl)

**功能**：对图片进行多视角渲染，输出摄影语义

- **输入**：仅接收来自图片节点的输入
- **操作**：调节旋转、缩放、FOV 等参数
- **输出**：供下游 AI 消费的摄影语义

## 第五部分：连线规则速查

| 源模块 | 可连接目标 |
|--------|------------|
| 文本 | LLM、文本拆分、图片、视频、音频 |
| LLM | 文本拆分、图片、视频、音频 |
| 文本拆分 | 图片、视频、音频 |
| 图片 | LLM、视频、3D 视角、音频（参考图） |
| 视频 | 图片（首帧/末帧）、音频（提取）、角色 |
| 音频 | 图片（参考音）、音频（人声/背景分离） |
| 角色 | 仅接收视频 |
| 3D 视角 | 仅接收图片 |

**特殊连线**：
- 视频 → 图片：可选择「首帧」或「末帧」
- 视频 → 音频：提取视频中的音频
- 音频 → 音频：人声分离时，可选择「人声」或「背景音」

## 第六部分：任务列表与批量运行

### 6.1 任务列表

- **位置**：左侧边栏
- **内容**：当前项目下进行中的图片、视频、音频任务
- **状态**：等待中、生成中、成功、失败
- **操作**：预览、下载、删除任务

### 6.2 批量运行

- **入口**：画布上的「批量运行」按钮
- **逻辑**：按依赖顺序依次执行可执行节点（图片、视频、音频、LLM）
- **显示**：运行中按钮变绿，显示「运行 X 个任务」

## 第八部分：典型工作流示例（可作视频演示）

### 示例 1：文生视频

1. 新建项目，进入画布
2. 添加文本节点，输入「一只小狗在草地上奔跑，阳光明媚」
3. 添加视频节点
4. 从文本右侧连接点拖到视频左侧连接点
5. 在视频节点右侧面板选择模型（如 Sora 2）、比例 16:9
6. 点击「文生视频」生成
7. 在任务列表查看进度，生成完成后在节点中预览

### 示例 2：图生视频

1. 添加图片节点，上传或生成一张参考图
2. 添加视频节点
3. 将图片连到视频
4. 输入提示词「人物缓缓转头看向镜头」
5. 点击「图生视频」生成

### 示例 3：口型同步视频

1. 添加文本节点，输入台词
2. 添加音频节点，选择 Index-TTS2，上传参考音，生成语音
3. 添加图片节点，上传角色参考图
4. 添加视频节点，选择 LTX 2.3 口型同步模型
5. 将图片、音频都连到视频
6. 点击生成

### 示例 4：音频裁剪

1. 添加音频节点，生成或上传音频
2. 选中音频节点，点击下方「裁剪」
3. 在全屏弹窗中拖拽双指针选择区间，试听
4. 点击「确认」完成裁剪

### 示例 5：LLM 扩写 + 文生图

1. 添加文本节点，输入「一只猫」
2. 添加 LLM 节点，连接文本，输入「请将上述描述扩展为详细的图片提示词」
3. 添加图片节点，连接 LLM
4. 批量运行，先执行 LLM，再执行图片生成

## 第九部分：常见问题与注意事项

### 9.1 输入法

- 提示词输入框支持中文 IME，输入中文选词后会自动保存，无需额外操作

### 9.2 余额不足

- 生成前会检查余额，不足时提示前往设置充值

### 9.3 生成失败

- 检查 API Key 是否正确
- 检查网络连接
- 查看任务列表中的错误信息

### 9.4 资源路径

- 本地资源使用 `local-resource://` 协议，项目路径变更可能导致资源失效

## 第十部分：视频大纲建议结构

建议按以下结构组织讲解视频：

1. **开场**（约 1 分钟）：软件介绍、适用场景

3. **项目管理**（约 1 分钟）：新建、切换、删除项目
4. **画布基础**（约 3 分钟）：缩放、平移、添加节点、连线、删除
5. **文本与 LLM**（约 3 分钟）：文本节点、LLM 节点、连线与运行
6. **图片生成**（约 5 分钟）：文生图、图生图、模型与参数、提示词标签、画板、下载
7. **视频生成**（约 5 分钟）：文生视频、图生视频、口型同步、裁剪
8. **音频生成**（约 4 分钟）：TTS、全能写歌、人声分离、裁剪
9. **角色与 3D 视角**（约 2 分钟）：角色创建、3D 视角控制
10. **任务列表与批量运行**（约 2 分钟）：任务状态、批量运行
11. **设置与配置**（约 2 分钟）：API Key、主题、连接线样式
12. **完整案例演示**（约 5 分钟）：选一个典型工作流从头到尾演示
13. **收尾**（约 1 分钟）：总结、常见问题、获取帮助

**总时长建议**：约 35–40 分钟
