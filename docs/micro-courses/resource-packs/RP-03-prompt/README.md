## 2. 天庭样例 · 填好的示范稿

```
@图片3 是林凡，@图片4 是玉皇，@图片2 是背景天庭金殿，@图片1 是木棍。
风格色调：需要写实真实风格，暗青色色调。
剧情：
1. 内景 天庭金殿 - 日
金殿恢弘，仙气缭绕。大门轰然破开，林凡手持一根破旧木棍昂首踏入。众仙惊愕，玉皇大帝冷眼扫视。

林凡  （怒目而视）  玉皇！今日，我带着这根木棍，来讨一个公道！

玉皇大帝  （冷笑）  一个凡人，手持腐朽木棍，也敢闯我天庭？公道？你配吗？
```

## 3. 出片前 12 条自检

| # | 检查项 | 过 / 不过 |
|---|--------|-----------|
| 1 | `@图片N 是…` 与参考槽序号一致 | |
| 2 | 场景写「背景××」，道具不写成人名 | |
| 3 | 风格色调只有「风格+色调」，无运镜说明书 | |
| 4 | 剧情像剧本，不像「主体定义/详细描述」 | |
| 5 | 无「背影镜头/特写镜头」等脏机位词 | |
| 6 | 系统台词说话人是「系统」，不是角色名 | |
| 7 | 无「系统：」「【系统】」当画面字残留 | |
| 8 | 弹幕已改成屏字描述，无裸【弹幕浮字】 | |
| 9 | 无「内心OS」「【旁白】」标签 | |
| 10 | 英文稿里对白在 `<d>[Chinese]…</d>` | |
| 11 | 仅说话人张嘴；系统声不绑角色 Audio | |
| 12 | 改图后已「重新导入提示词」或确认手改仍有效 | |

## 4. 常见失败归因卡

| 现象 | 优先查 |
|------|--------|
| 念出「保持 Picture 1…」 | 上云误发了中文导演词 / 英文稿混入说明句 |
| 角色脸串到别人 | `@图片` 绑错槽；或 Subject 与 Picture 错位 |
| 白底棚拍渗进成片 | 角色图当环境用了；规则应「只锁外貌」 |
| 系统声从主角嘴出 | dialogue_character_id 不是 system；Audio 槽错绑 |
| 风格发金发紫 | 风格行与参考图冲突；统一写实暗青并锁 Pic 环境 |

## 5. 质检工作坊用 · 病句改写（答案要点）

**病句**：`主体定义：… 详细描述：中景固定… 视线 脑海中… 背影镜头。`

**改写方向**：

```
@图片1 是背景××，@图片2 是某某。
风格色调：需要写实真实风格，暗青色色调。
剧情：
1. 内景 ×× - 日
某某站起身，朝远处走去。
```

（机位不进剧情正文；非视线的「脑海中」删除。）
