## 2. 最小工作流拓扑（作业模板）

```
[文本节点：标题文案]
        ↓
```

## 3. 连接线操作速查

| 操作 | 结果 |
|------|------|
| 单击连接线 | 高亮选中 |
| 再点同一条 | 中点出现剪刀 |
| 点剪刀 / Delete | 删除该边 |
| 点空白画布 | 取消选中 |

## 4. 排障口诀（讲师用）

1. **灯不亮**：先查 Key，再查网络，最后看主进程日志。  
2. **任务一直转**：RunningHub 在轮询，看任务 ID 是否写出。  
3. **前端报跨域**：错误用法；必须走 IPC，不要在渲染进程 fetch。  
4. **重启丢内容**：确认是否写在正确 `projectId`；勿开两个同工程窗口互踩。
