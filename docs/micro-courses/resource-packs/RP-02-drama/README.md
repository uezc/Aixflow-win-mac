## 1. 流程门禁卡（贴显示器）

```
剧本分集 ──下一步──► 画风色调 ──锁定──► 剧本分析
                                      │
                              ④确认后才可
                                      ▼
              素材准备 ──确认──► 导演分镜 ──出片──► 成片入轨
```

**禁止**：未锁风格进分析；未确认分析进素材；素材未齐就批量出片。

```
江澈  （愣住）  系统，你在吗？
```

## 3. 样例剧本 B · 天庭对峙（练多角色+道具）

```
1. 内景 天庭金殿 - 日
金殿恢弘，仙气缭绕。大门轰然破开，林凡手持破旧木棍昂首踏入。
众仙惊愕，玉皇大帝冷眼扫视。

林凡  （怒目）  玉皇！今日，我带着这根木棍，来讨一个公道！

玉皇大帝  （冷笑）  一个凡人，手持腐朽木棍，也敢闯我天庭？公道？你配吗？

林凡  （坚定）  十年前，你以天庭之名灭我师尊……今日，我要用这棍，让你看看凡人的愤怒！

【特效：众仙窃窃私语，神光微颤。】
```

## 4. 分镜时长凑档速查

| 相邻短镜 | 常见合并结果 |
|----------|----------------|
| 10 + 10 | → 20（若产品允许）或保持拆镜策略以产品为准 |
| 6 + 10 | → 15 |
| 6 + 6 | → 10 |

落档只认产品支持的秒数（常见 6 / 10 / 15）。

## 5. 成片交付检查表

- [ ] 每镜都有成片或明确失败原因  
- [ ] 角色脸与定妆图可辨认  
- [ ] 场景未吃角色图白底  
- [ ] 对白未出现「念导演词 / 念标签」  
- [ ] 顺序与剧本场次一致  
- [ ] 导出样片竖/横与发行渠道一致
