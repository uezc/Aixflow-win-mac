# MC-03 · 提示词与出片进阶（10 节）

**服务定位**：解决「会点流程但成片飘、串台、念导演词」的进阶问题。  
**对应功能**：中文白话编译稿、英文 H3 八段、参考图绑定、系统声/旁白、视线与脏机位清洗、重新导入提示词。

---

## 学习目标

- 会写 / 会改白话提示词：`@图片N 是谁` + `风格色调` + `剧情`  
- 理解上云为何发英文、中文稿给编辑看  
- 会处理系统声、弹幕屏字、道具绑定，会做出片前自检  

## 课表（10 节）

| 节 | 标题 | 时长 | 实操要点 | 验收标准 |
|----|------|------|----------|----------|
| 01 | 为什么要白话：编辑稿 vs 出片稿 | 10′ | 对比中文白话与英文 8 段 | 能说清「谁给人看、谁给模型」 |
| 02 | `@图片` 绑定：人 / 景 / 道具 | 12′ | 按槽位写清林凡、玉皇、金殿、木棍 | 绑定句与参考图序号一致 |
| 03 | 风格色调一行写对 | 8′ | 写「写实真实风格，暗青色色调」类 | 无 CGI 金辉乱串 |
| 04 | 剧情区：场次头 + 动作 + 对白 | 15′ | 剧本式排版，括注情绪，特效另起行 | 读起来像剧本不是说明书 |
| 05 | 系统声与全息面板 | 12′ | 系统台词进「系统」说话人，不当画面字 | 成片不念「系统：」标签 |
| 06 | 弹幕 / 屏字 / 旁白清洗 | 12′ | 【弹幕浮字】→ 屏字描述；去掉【旁白】标签 | 无脏标签进画面 |
| 07 | 脏机位词：背影镜头等必须剥离 | 10′ | 从动作里删机位词，运镜走 camera | 剧情区无「××镜头」 |
| 08 | 英文 H3：何时切换、看什么段 | 15′ | 切英文看 subject_definitions / detailed_description / `<d>` | 能指出对白是否在 `<d>` |
| 09 | 重新导入提示词与防串台 | 12′ | 改参考图后重编译；检查说话人口型隔离 | 换图后绑定句更新 |
| 10 | 出片质检工作坊 | 20′ | 用 RP-03 自检表过 2 条失败样例 | 交：问题归因 + 改后提示词 |

## 讲师备注

- 默认 UI 已是中文编译稿；强调「重新导入」会覆盖手改，先备份。  
- 系统声务必配 Audio 参考，避免落到角色口型。  
- 天庭样例可直接用用户熟悉的林凡 / 玉皇映射练习第 02–04 节。

> 已完成《提示词与出片进阶》10 节微课，能独立编写白话提示词、处理系统声与屏字，并对英文出片稿做基础质检。
