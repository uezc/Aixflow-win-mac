# MC-01 · 画布工作流入门（10 节）

**服务定位**：让学员在 1 天内能独立完成「建工程 → 连节点 → 出一张图/一段视频 → 保存打包」。  
**对应功能**：NEXFLOW 画布、节点工厂、BLTCY / RunningHub 双平台、财务看板、工程持久化与 `.nexflow` 打包。

---

## 学习目标

- 会配置双平台 Key，并看懂余额 / RH 币 / 心跳灯  
- 会用节点工厂搭一条最小可跑通工作流  
- 会保存工程、导出分享，理解「主进程直连、前端不 fetch」带来的稳定性  

## 课表（10 节）

| 节 | 标题 | 时长 | 实操要点 | 验收标准 |
|----|------|------|----------|----------|
| 01 | 认识 NEXFLOW：画布 vs 导演台 | 10′ | 打开软件，区分工作区与短剧导演入口 | 能指出「我现在在哪条产品线」 |
| 02 | 设置中心：双平台 Key 与心跳灯 | 12′ | 填 BLTCY / RunningHub Key，看余额 | 右上角余额或币数可见且灯亮 |
| 03 | 新建工程与实时保存 | 8′ | 建项目、拖节点、改文字，关开软件验证 | 重启后节点位置与文字仍在 |
| 04 | 节点工厂：文本 / 图片 / LLM | 15′ | 按 manifest 长出的控件跑一条文生图或文生文 | 产出进入下游节点 |
| 05 | 连接线操作：选中 → 剪刀删除 | 8′ | 两步选中、剪刀删除、Delete 键 | 能安全改拓扑不误删 |
| 06 | 大脑引擎 BLTCY：大模型调用 | 15′ | Gemini / Sora 类能力一次真实调用 | 任务成功或能读懂失败原因 |
| 07 | 插件引擎 RunningHub：提交与轮询 | 15′ | 提交小应用，等结果回写 | 理解「提交→轮询→结果」 |
| 08 | 财务看板与用量习惯 | 10′ | 看余额变化，记录一次调用成本 | 能写出「本次大约花了多少」 |
| 09 | 工程打包与分享 `.nexflow` | 12′ | 导出 ZIP（JSON+素材），另一机导入 | 对方能打开同一拓扑 |
| 10 | 综合小作业：最小商业工作流 | 20′ | 模板：标题文案→封面图→竖版预览 | 交作业：截图 + 导出包 |

## 讲师备注

- 强调：**前端不跨域 fetch，所有联网走主进程 IPC**（排障话术）。  
- OEM 客户：第 02 节可换成「你们品牌后台的 Key 入口」。  
- 作业批改用 **RP-01** 检查表。
