# NEXFLOW 微课 · 逐节功能对照表（GPT 写课专用）

> 用途：把本文件整份或按节粘贴给 GPT，生成逐字稿 / 分镜脚本 / 练习题。  
> 红线：**禁止**写充值、套餐、余额催付；**禁止**出现 BLTCY、RunningHub 等第三方算力品牌名；只写「软件设置 / 内置算力 / 接口配置」。

---

## 全局产品事实（写课时必须遵守）

| 维度 | 内容 |
|------|------|
| 产品定位 | 桌面端 AI 多模态**节点工作流**：文本 / LLM / 图片 / 视频 / 音频 / 角色 / 3D 视角等模块连线组合 |
| 主界面 | 项目列表页 ↔ 画布工作区；顶部栏、左侧任务列表、中央画布、选中节点后的底部/右侧配置区 |
| 核心交互 | 拖拽节点、从「+」把手连线、滚轮缩放、拖空白平移、自动保存、导出 `.nexflow` 工程包 |
| 任务系统 | 左侧任务列表：等待中 / 生成中 / 成功 / 失败；可预览、下载、删除 |
| 批量运行 | 画布「批量运行」：按依赖顺序执行 LLM / 图 / 视频 / 音频 |
| 连线规则摘要 | 文本→LLM/拆分/图/视频/音频；图片→视频/3D/LLM；视频→图(首/末帧)/音频提取/角色；音频→TTS下游或人声分离；图+音频→口型视频 |

# U1 · 熟悉软件 · 界面 · 基础用法（第 01–05 节）

## 第 01 节 · NEXFLOW 是什么：画布工作流一览

| 项 | 内容 |
|----|------|
| **课程目标** | 建立「节点 = 工序、连线 = 物料传递」心智模型 |
| **对应功能** | 产品定位说明；画布工作流概念；典型链路示意（文本→图 / 文本→视频 / 图+声→口型） |
| **界面/入口** | 启动后项目列表；进入任一空项目画布；不要求真实生成 |
| **演示步骤** | ① 打开软件说明这是工作流工具 ② 指画布中央 ③ 口头举例三条最短链路 ④ 对比「单点工具」vs「可拼接流水线」 |
| **不做** | 不讲充值；不讲第三方平台名 |
| **验收** | 学员能用一句话说：「把文字、图、声、视频模块连起来出片」 |
| **建议时长** | 8–10′ |
| **给 GPT 的写作提示** | 用生活比喻（工厂流水线）；准备 1 张拓扑示意图描述；结尾预告后面会拆开图/声/视频 |
